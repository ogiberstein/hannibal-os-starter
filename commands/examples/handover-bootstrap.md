# Handover bootstrap command example

Use the handover-bootstrap skill to create a public-safe project-control packet for my private native-Hermes workspace.

Scope:
- Work only in the private project/control workspace I provide.
- Create or update `BRIEF.md`, `STATUS.md`, `DECISIONS.md`, and `AGENTS.md`.
- Use profile labels and placeholders; do not include raw platform IDs.
- Mark runtime compatibility INCONCLUSIVE unless exact Hermes version plus preflight/smoke evidence are present.
- Do not create custom router, deployment, hardening, or recovery machinery.

This command example does not automatically install anything into Hermes. Copy or adapt it only after review.
