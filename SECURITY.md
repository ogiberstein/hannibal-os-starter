# Security Policy

This repository is a starter/reference kit, not a security product.

## Reporting a vulnerability

If you find a vulnerability in a script or example, open a private security advisory or contact the maintainers privately. Do not file public issues containing secrets, tokens, raw platform IDs, transcripts, logs, or exploit details against live systems.

## Public-safe diagnostics

When asking for help, share only:

- repo commit SHA
- command run
- redacted error text
- placeholder config snippets
- sanitation/verification output with sensitive values removed

Never share `.env`, credentials, raw platform IDs, private message contents, runtime memory, session files, backups, or logs from a live system.
