# Evidence gate command example

Use the evidence-gate skill to review my private native-Hermes profile/routing setup.

Scope:
- Build a claim ledger for Chief-of-Staff DM routing, one explicit project route, unmatched `default` fallback, the exact installed version's documented missing-target behavior, and observable runtime/rollback identity.
- Use PASS, PASS WITH RISKS, FAIL, or INCONCLUSIVE.
- Treat missing transport or runtime evidence as INCONCLUSIVE, not PASS.
- Keep the review read-only unless I separately approve a profile, route, gateway, service, credential, cron, or runtime change.
- Redact or omit secrets, raw platform IDs, message contents, logs, sessions, memories, backups, host details, and customer-private data.

This command example does not automatically install anything into Hermes. Copy or adapt it only after review.
