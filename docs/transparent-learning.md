# Transparent Learning

If an operator improves the starter from real usage, the learning loop should be explicit and consent-based.

## Allowed public learning

- Redacted failure categories.
- Generic workflow improvements.
- Placeholder-safe docs.
- Reusable checks and scripts.

## Not allowed without explicit permission and sanitization

- Raw transcripts.
- Private logs.
- Customer-sensitive examples.
- Credentials or platform IDs.
- Memory/session files.
- Business-private project details.
