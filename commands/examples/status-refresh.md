# Status refresh command example

Use the status-refresh skill to refresh the project `STATUS.md` in my private deployment.

Scope:
- Read `STATUS.md`, `BRIEF.md`, `DECISIONS.md`, and `AGENTS.md` first.
- Separate Verified facts from Inference.
- Include one concrete `Next:` line.
- Do not include secrets, raw platform IDs, message contents, logs, sessions, memories, or backup artifacts.

This command example does not automatically install these into Hermes. Copy or adapt it into your private deployment's command system only after reviewing it.
