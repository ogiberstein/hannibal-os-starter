# Handover bootstrap command example

Use the handover-bootstrap skill to create a public-safe project packet for my private deployment.

Scope:
- Work only in the private deployment workspace I provide.
- Create or update `BRIEF.md`, `STATUS.md`, `DECISIONS.md`, and `AGENTS.md`.
- Use labels and placeholders for messaging routes; do not include raw platform IDs.
- Mark runtime readiness as INCONCLUSIVE unless preflight and smoke-test evidence are present.

This command example does not automatically install these into Hermes. Copy or adapt it into your private deployment's command system only after reviewing it.
