# Evidence gate command example

Use the evidence-gate skill to produce a go/no-go readiness review for my private deployment.

Scope:
- Build a claim ledger for project route, default/Chief-of-Staff route, restart/recovery, and scheduled update delivery.
- Use PASS, PASS WITH RISKS, FAIL, or INCONCLUSIVE.
- Treat missing transport or runtime evidence as INCONCLUSIVE, not PASS.
- Redact or omit secrets, raw platform IDs, message contents, logs, sessions, memories, backups, and customer-private data.

This command example does not automatically install these into Hermes. Copy or adapt it into your private deployment's command system only after reviewing it.
